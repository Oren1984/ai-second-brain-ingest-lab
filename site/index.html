AI systems engineering · human-in-the-loop knowledge

A second brain that asks before it learns.

A new source arrives. The ingest reads it against what the wiki already believes, spots a contradiction and proposes page changes. A human approves, edits or rejects each one — only then does the knowledge change, with links, an index and an audit trail.

      Validation
      
          
      Run before writing (preflight) and again after. Warnings are signals for a human, not failures.
      
          
      
        
      
        
      
          
      Log entry
      
          
      Appended to wiki/log.md only because changes were applied. A full rejection writes nothing to the wiki.
